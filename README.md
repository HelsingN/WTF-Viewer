# WTF Viewer

Research and monitoring workspace for tracking events, evidence, analytical models, reports, and review workflows.

**Initial focus:** AI CapEx Signals · **Initial model:** Challenger 2.1.

## Project status

**Specification only.** This repository currently contains the product specification and project documentation. Application implementation requires a separate instruction from the project owner.

## Specification

- [Product and technical specification — Russian / English](docs/SPEC_RU_EN.md)

## Scope

WTF Viewer is the product. AI CapEx Signals is its first research workspace. Existing AI CapEx Reversal research remains canonical in [HelsingN/AI_CapEx_Reversal](https://github.com/HelsingN/AI_CapEx_Reversal); source access may require authorization.

The specification covers:

- HIGH/CRITICAL event calendar and a stable-ID evidence registry.
- Initial/final assessments, qualification and recalculation decisions.
- Daily/weekly reports, completeness checks and resumable research context.
- Challenger 2.1 artifact/component history without score carry-forward.
- Separate macro comparisons and combined qualitative effects.
- Manual PR, CI, review and merge tracking; no automatic research-repository writes.
- RU/EN interface, persistent notes, filters and duplicate-safe import/export.

No application source, private research snapshots or event datasets are included.
