Приложение соответствует проверенному коммиту этапа 6 `5f0a115743a952b0d4d90a974fc9e4b39bc7eae0`. На этапе 7 добавлены проверки и документация выпуска. Файлы входа, API и миграция D1 совпадают с опубликованной версией. Сценарий локальной проверки создаёт временную D1 и проверяет существующую в ней запись. Рабочая D1 в этом сценарии не используется.

CI состоит из `Build, contracts and reader` и `Challenger parity with Python`. Повторить основной прогон можно через `npm run install:ci`, `npm run check`, `npm run check:research-package`, `npx --no-install tsc --noEmit`, `npm run build`, `npx --no-install playwright install chromium` и `bash scripts/checks/run-reader.sh`. Для паритета используется `npm run check:challenger`.

[Трекер приёмки](ACCEPTANCE_TRACKER.md) сохраняет отдельный статус проверки авторизованного доступа к действующему Site. Редакторские сценарии A01–A18 остаются в исходной области backlog.
