# Challenger 2.1 в WTF Viewer

Раздел **Challenger** открывает артефакт активного пакета и форму локального пересчёта. По умолчанию указана дата исходного среза. Укажите ISO-дату с часовым поясом, например `2026-11-11T08:17:14+02:00`. Дата оценки может быть равна исходному срезу или следовать за ним. Более поздняя дата пересчитывает срок действия исходных наблюдений и событий.

Вход — структурированный snapshot основного недельного артефакта из проверенного исследовательского пакета. Сборщик читает Git-объекты по зафиксированному SHA и проверяет расчёт на исходную дату. Текущая версия принимает закреплённую модель, код Python и код политики 2.1 по SHA-256. События берутся из snapshot, связанного с артефактом. Реестр, отчёты и `PROPOSED` остаются доступны для просмотра. Оценки фактов и их квалификации вводятся через принятые источники.

## Локальное состояние и экспорт

Результат помечен `LOCAL / UNPUBLISHED`. Исходный артефакт отображается отдельно. JSON результата содержит интервал, точную оценку при её наличии, покрытие, факторы, учтённые и исключённые события, причины UNKNOWN, ссылку на вход и версии модели, политики и кода.

Ключ строится из SHA-256 структурированного входа, версий и нормализованного `evaluation_as_of`. Дата первого локального вычисления хранится отдельно. При перезагрузке UI восстанавливает последний успешный срез для этого входа или выполняет расчёт по cutoff пакета. Для восстановления хранятся только ключи и даты, результат вновь вычисляется в браузере. Ошибка запроса сохраняет предыдущий локальный результат и его дату. Импортированный пакет остаётся локальным. Пересчёт и выгрузка не создают отчётов или коммитов.
