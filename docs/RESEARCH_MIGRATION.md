Дата сверки: 21 ноября 2026, Asia/Jerusalem.

Репозиторий AI_CapEx_Reversal хранит исходную историю перенесённой области. Перенос касается GitHub. Текущий сайт продолжает использовать встроенный снимок до реализации импорта.

- [Опись переноса](../research/migration-manifest.json) содержит 192 записи: 175 из исходного main и 17 файлов предложений из восьми открытых PR. Для каждой записи указаны исходный путь, коммит, Git blob SHA, SHA-256 и целевой путь. Пути предложений включают номер PR.
- [Указатель отчётов](../research/reports/README.md) открывает 19 ежедневных и 8 еженедельных текстов из main, архивный Weekly Watch от 4 ноября, ежедневные отчёты от 16 и 17 ноября в черновиках и предложенный Weekly Watch от 18 ноября. Частичный материал от 9 ноября доступен в архиве с исходным статусом.
- [Реестр событий](../research/challenger/events/challenger_v2_event_registry.json) сохраняет все 47 исходных ID и историю проверок. Перенесены модель, политика, наблюдения, входы, приложения, индексы, артефакты и Python-эталон.

Для текстов и приложений посчитаны SHA-256. Git blob SHA для всех 192 файлов совпали в исходном и целевом деревьях. Сверены принадлежность материалов исходным PR на указанных SHA, уникальность 47 ID и их формирование из исходных ключей и дат. 136 ссылок из Markdown сопоставлены с целевыми файлами, ещё 18 указывают на зафиксированный исходный архив. Опись сохраняет одну исходную битую ссылку из архивной модели v1. Связанный материал доступен в разделе исследований. Проверка охватывает внутренние ссылки и файлы репозиториев.

На восстановленной структуре исходных файлов прошли 99 тестов Challenger и проверка формата недельного снимка 11 ноября. Снимок сохранил статус PARTIAL с двумя нерешёнными полями R4. Датированный эталонный расчёт 4 ноября воспроизведён локально как проверка переноса.

Перед автоматической доставкой пакетов нужно сверить места, куда пишут AI CapEx Watch, Daily Close и Event Alerts, и перевести публикацию Challenger и отчётов на один рабочий источник. На этапе 2 пользовательский цикл начинается со сборки пакета из конкретного коммита WTF-Viewer. Расписания и публикация сайта относятся к следующим этапам.
