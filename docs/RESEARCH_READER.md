# Просмотр исследований и отчётов

Reader этапа 4 использует активный исследовательский пакет. Ежедневные и еженедельные отчёты берутся из его индекса. Поиск охватывает полный текст отчётов и исследований. Карточка отчёта показывает наличие файла, комплектность, статус по источнику, cutoff и сессию США, если эти сведения есть в источнике. Для отсутствующих сведений выводится `UNKNOWN`.

Поддерживаются заголовки, списки, цитаты и GFM-таблицы. Связанные файлы открываются из списка приложений и по ссылкам из manifest переноса. Связь недельных структурированных артефактов с отчётом использует его дату и происхождение. Внешние источники используют ссылки HTTP(S). Исходный HTML пропускается, внешние изображения отображаются текстом, а недоступные ссылки получают явную отметку. Исходный файл можно скачать или открыть в GitHub на SHA выбранного пакета.

Календарь группирует записи по дате события. В календаре и реестре доступны исходный ID, время подтверждённой публикации, консервативный public-by, время регистрации, источники и история проверок. История расчётов показывает файлы из пакета, включая архивные и предложенные. На обзоре доступны исходный артефакт Challenger, локальный результат и открытые проверки из выбранного snapshot.

## Проверка этапа 4

22 ноября 2026 года выполнены production-сборка Vinext/Wrangler, проверка типов и ESLint изменённых компонентов. Прошли проверки контрактов, исследовательских пакетов и 39 сценариев совместимости Challenger с Python.

В Chromium проверены обзор и локальный расчёт, просмотр недельного отчёта за 11 ноября с таблицами и переходом к JSON-артефакту, дневной отчёт за 17 ноября из PR #229, переход между исследованиями, календарь с четырьмя датами события и связанный расчёт. Проверены отсутствие горизонтального переполнения страницы при 390 CSS px и английский экран истории при 1280 CSS px. Контрольный пакет с HTML и небезопасной ссылкой подтвердил фильтрацию HTML и URL, сохранение цитаты и отсутствие сетевой загрузки внешнего изображения.

B02 проверен локально. B08 остаётся в работе до этапа 5. Релизная browser-приёмка и проверка существующего Sites запланированы на этапе 7.
